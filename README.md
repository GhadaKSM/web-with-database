# web-with-database
📌 Description

This project is a simple web application built using HTML, PHP, and MySQL. It allows the user to:

Submit a Name and Age through a form.
Store the submitted data in a MySQL database.
Display all stored records in a table below the form.
Toggle the Status of each record between 0 and 1 using a button.
Reflect the updated status immediately on the page after clicking Toggle.
